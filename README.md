# Rick & Morty Encyclopedia 🛸

Веб-додаток для перегляду персонажів, епізодів і локацій всесвіту Rick and Morty.

Побудований на [Next.js 16](https://nextjs.org/) з використанням [Rick and Morty API](https://rickandmortyapi.com/).

## Стек технологій

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**

## Функціонал

- 🧬 Перегляд усіх персонажів з фільтрацією за статусом і пошуком
- 📺 Список усіх епізодів з фільтрацією по сезонах
- 🌍 Список локацій з фільтрацією по типу
- 📄 Детальні сторінки для кожного персонажа, епізоду та локації
- 📱 Адаптивний дизайн

## Запуск локально

1. Клонуй репозиторій
2. Встанови залежності:
   ```bash
   npm install
   ```
3. Запусти сервер розробки:
   ```bash
   npm run dev
   ```
4. Відкрий [http://localhost:3000](http://localhost:3000)
